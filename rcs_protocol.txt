==RCS protocol==
Commands are case sensitive and in CamelCase. Do not include the "<" or ">".
Numbers use "." as the decimal separator.
Send "Help" to a running server for the list of commands it supports.

Error Responses:
    Error: Invalid Command                  the command does not exist
    Error: missing argument for <cmd>
    Error: invalid number in <cmd>
    Error: could not set <name> to <value>
    Error: could not read <name>
    Error: magnet is moving                 a SetMagnetDAC/SetMass move is still running
    Error: <message>                        anything else that went wrong

Command	Arguments	Returns	Note

===========General================================================
GetVersion		20.2
Help		comma separated command names
GetData		see note	tag_data=true: name,value pairs e.g. H2,aaa,L1,bbb,CDD,ccc
				tag_data=false: values only. "Error: no data" before the first scan
ProbeScanData		OK	log the structure of the next scan to the Qtegra log (diagnostic)
GetTuningSettingsList		comma separated names
SetTuningSettings	name	OK,Error
GetIntegrationTime		seconds
SetIntegrationTime	seconds	OK,Error
BlankBeam	true,false	OK,Error	true sets Y-Symmetry to -50, false restores the previous value

===========Cup/SubCup Configurations==============================
GetCupConfigurationList		names separated by \r
GetSubCupConfigurationList	cup name	names separated by \r
GetActiveCupConfiguration		name
GetActiveSubCupConfiguration		name
GetSubCupParameters		Deflection <det> Set,value;...;CDD Supply Set,value
ActivateCupConfiguration	cup name sub cup name	OK,Error

===========Ion Counter============================================
ActivateIonCounter	detector	OK,Error	activate and unprotect one CDD, restart the monitor scan
DeactivateIonCounter	detector	OK,Error	deactivate and protect one CDD, restart the monitor scan
ActivateAllCDDs		OK,Error
DeactivateAllCDDs		OK,Error

===========Ion Pump Valve=========================================
Open	valve name	OK,Error
Close	valve name	OK,Error
GetValveState	valve name	True,False,Error	True=open, False=closed

===========Magnet=================================================
GetMagnetDAC		5.0
SetMagnetDAC	value 0-10V	OK,Error	large moves are stepped in the background
GetMagnetMoving		True,False
SetMass	mass[,cup]	OK,Error	cup defaults to AX. deactivates the CDDs first

===========Source=================================================
GetHighVoltage		V
SetHighVoltage	V	OK,Error
GetHV		kV
SetHV	V	OK,Error	NOTE: takes V although GetHV returns kV

==========Detectors===============================================
ProtectDetector	name,On|Off	OK	On moves the deflection to 2000, Off restores it
GetDeflection	name	100
SetDeflection	name,value	OK,Error
GetDeflections	name[,name,...]	comma separated values, 0 if unreadable
GetIonCounterVoltage		1730
SetIonCounterVoltage	value	OK,Error
GetGain	name	value,Error
SetGain	name,value	OK,Error

==========Generic Device==========================================
GetParameter	name	value,Error	any device listed in the hardware database
SetParameter	name,value	OK,Error
GetParameters	name[,name,...]	comma separated values, 0 if unreadable
